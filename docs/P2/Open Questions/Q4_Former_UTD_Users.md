# Q4 - Former UTD Users

## Question
What if an existing user is no longer part of the UTD community?

## Final Answer
If a user isnt part of the UTD community anymore their account should be deactivated and/or restricted from using core Comet Carpool features. 

The system should usually require users to reverify their UTD email or place an "Expected Graduation Date". If they no longer can verify email access they shouldnt be allowed to create rides, requests, or use the application in general.

## Reasoning
This is specifically designed for the UTD community. By allowing former students to continue using the system could create trust issues, and safety concerns. 

Reverification helps make sure active users are still attending UTD without requiring constant verification.

## Impact
- Requirements: Add account reverification or expected graduation date and inactive account handling.
- Use Cases: Add a reverify account process.
- Design/Architecture: Store verification status and last verification date for each user.
