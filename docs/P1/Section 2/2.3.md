# 2.3 User characteristics

## Student drivers
Student drivers are university students who have access to a vehicle and are willing to offer available seats to other students.
They are expected to have basic experience using common web or mobile applications, but the system does not require advanced technical knowledge.
Drivers may access the system from either a smartphone or a computer and may need to create or update ride information quickly before traveling.
Therefore, the interface should make common actions easy to understand and complete.

## Student passengers
Student passengers are university students who are looking for transportation to or from campus or other agreed destinations.
They are expected to be familiar with basic web or mobile applications, but they should not need advanced technical knowledge to use the system.
Passengers may often use the system from a smartphone and may need to find a suitable ride quickly based on location, date, and departure time.
Ride information and request status should therefore be presented clearly.

## System administrators
System administrators are users responsible for basic system management and moderation.
They are expected to have a higher level of familiarity with the application than regular users, but they should not need programming or database knowledge to perform administrative tasks.
Administrators are more likely to use the system from desktop or laptop computer when reviewing user accounts, reports, or other system information.
