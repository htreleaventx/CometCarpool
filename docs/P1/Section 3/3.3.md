# 3.3 Constraints requirements

| ID | Constraint - one sentence | Source | Why it cannot be negotiated | 
|---|---|---|---|
| CON-01 | The system shall restrict account creation and system access to members the UTD community | R2 | CometCarpool is specifically intended for UTD students, so unrestricted public access would change our defined scope and target users |
| CON-02 | The system shall not process, store, or transfer payments between riders and drivers | R2 | Payment processing was excluded from the project scope because it introduces additional finances, security, and legal responsibilties | 
| CON-03 | The system shall not provide real time GPS tracking of riders or drivers | R2 | Real time tracking was excluded because of privacy, safety, and implementation concerns |
| CON-04 | The system shall not automatically import a students official class schedule | R2 | Accessing official class schedules would require external systems and permissions that are outside the project scope |
