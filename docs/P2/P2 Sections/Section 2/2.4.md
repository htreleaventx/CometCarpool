# 2.4 Constraints

## 1. User eligibility constraint

Access to Comet Carpool will be limited to verified members of the UTD community.

Source: S1, S2, R2

## 2. Payment processing constraint

Comet Carpool will not process, store, or transfer payments between riders and drivers.

Source: S1, S2, R2

## 3. Real-time GPS constraint

Comet Carpool will not provide real-time GPS tracking of riders or drivers.

Source: S1, S2, R2

## 4. Class schedule integration constraint

Comet Carpool will not automatically import a student's official UTD class schedule.

Source: S1, S2, R2

## Constraint Review

All four constraints were reviewed against the consolidated P1 documentation, the approved project scope, and the requirements in Section 3.3.

- CON-01 remains consistent with the system's intended UTD user community.
- CON-02 remains consistent with the exclusion of payment processing.
- CON-03 remains consistent with the exclusion of real-time GPS tracking.
- CON-04 remains consistent with the manual schedule entry functionality.

The original source references (S1, S2, R2) have been preserved.

### Review Status: Reviewed / No Update Needed

No changes to the four constraints are required. Their consistency should be maintained throughout the remaining architecture and deployment documentation.
