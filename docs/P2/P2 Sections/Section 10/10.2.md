This section describes the planned development activities and milestones following the completion of P2.

## Planned Activities

Describe the activities required to prepare for P3.

Consider the following areas:

- Review and finalize the P2 baseline.
- Address any unresolved analysis or architectural issues.
- Refine system design based on P2 feedback.
- Develop the detailed design artifacts required for P3.
- Plan implementation and testing activities.
- Assign responsibilities and establish deadlines.
- Review and integrate team contributions.

## Milestone Responsibilities

Portions that are better led by 1 person  alone listed as owned by 1 person. portions that would be best split between multiple people or everyone listed as such.

## Progress Tracking

Describe how GitHub Issues, milestones, pull requests, and the project board will be used to monitor progress toward P3.
GH issues will be used to track individual tasks, the project board will be used as an overview of what is done/needs to be done, pull requests will be used to track what has been submitted and ensure all code merges are reviewed, milestones will be used to track larger initiatives that have multiple components.

## Completion Criteria

Explain how the team will determine whether the planned P3 preparation activities have been completed.
Weekly meeting, ensuring milestones are met and recorded as met on GH
