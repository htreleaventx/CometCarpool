| Q1 | Users will be required to register using a valid UTD email address. | FR-01 should require a valid UTD email address |

| Q6 | Yes, there will be an automatic suspension and ban procedure when users receive enough reports | FR-14 should track reports and be extended to automatically suspend or ban users after multiple infractions. FR-01 should prevent users from accessing their account when it is suspended or banned, and it should also prevent the same UTD email from creating a new account. FR-01 should also inform users upon account creation that multiple infractions will result in a suspension or ban |
| Q7 | Yes, drivers can specify the number of available seats | FR-03 should be updated to include the number of available seats when posting a ride. A requirement should also specify how seat availability updates when riders are accepted or cancelled |

| Q9 | Rides and ride requests will automatically become inactive once their scheduled departure date and time have passed | FR-03 and FR-04 should define automatic expiration for posted rides and requests |
| Q11 | The search function will implement filtering results by date, time, pickup location, destination, and seats | FR-06 should include options to filter by date, time, pickup location, destination, and seats | 
| Q12 | A seat will only be reserved once the driver accepts a request | FR-03 and FR-05 should support specifying and tracking available seats |
| Q13 | Riders can cancel their ride request even after a driver has accepted them | FR-11 should clarify that riders can cancel requests after acceptance |
| Q14 | Drivers may cancel at any time before their ride is matched. | FR-02 should let drivers cancel their posted ride even after it has been matched, and it should provide a confirmation screen |
| Q15 | No, notifications will not be implemented | N/A |
| Q16 | The affected user will be able to report the incident through the application's reporting system | FR-14 should include "No-show" as a reporting category. FR-13 should continue to restrict ratings and reviews to completed rides |
| Q20 | No, contribution amounts will not currently be stored by the system | N/A |
| Q21 | Popups will be implemented reminded them of such | FR-12 should show a warning for a student that all voluntary contributions are unenforced |
