## System Boundary Explanation 
The UTD Ridesharing System is a web application designed to connect UT Dallas students offering rides with students seeking transportation.
The system’s scope includes creating and managing ride lists, searching for available rides, submitting and reviewing ride requests,
managing seat availability, handling cancellations, and basic administrative functions.
Student drivers, student passengers, and system administrators interact with the system as external participants. 
The system does not include real-time GPS tracking, route optimization, payment processing, or integration with external ridesharing platforms. 
No university authentication service or other third-party integration is planned at this stage,
allowing the team to focus on core functionality without relying on unverified external services.
