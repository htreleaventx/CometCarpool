# 4.4 Repository and tooling

CometCarpool team will use GitHub to store project documentation, track individual contributions, and manage changes throughout our project.

- **Repository URL:** [CometCarpool GitHub](https://github.com/htreleaventx/CometCarpool)
- **Main Branch:** `main`
- **Branch Convention:** Everyone will work from the latest version of `main`, but separate branches may be created for larger changes when needed
- **Commit Convention:** Each team member will commit their own work using messages and comments that describe what was added or changed such as 'Added Section 1.1 through 1.4 and its information'
- **Pulling Changes:** Team members can run `git pull --rebase origin main` before beginning their work or pushing changes to reduce merging conflicts
- **Issues:** GitHub issues may be used to assign larger tasks, document problems, and track work that still needs to be completed
- **Access:** All team members have access to the repo as well as the professor and grader so that repo history and individual contributions can be reviewed
- **Documentation:** Project documentation is stored in the `docs/` directory and organized into separate folders for P1, P2, and P3
